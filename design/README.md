# Design Directory

Rationale documents and design decisions live here. When the user requests a plan, the agent:

1. Conducts a deep interview (batched questions) until everything is clear.
2. Writes rationale (decisions, assumptions, trade-offs) into a document in this directory.
3. Reviews this directory when starting or revising plans to stay consistent.

Use descriptive filenames, e.g. `qpcr-import-rationale.md`, `auth-flow-decisions.md`.
