---
title: Statistics
description: Filterable counts and charts for specimens, containers, and storage
---

Open **Statistics** in the sidebar. Filters at the top apply to the whole page: study, source type, specimen type, container type, tags, collection or creation date range, and location. Active filters appear as removable chips. If filters match nothing, one empty-state message with **Clear filters** replaces the charts.

This page has no export button. For a file of matching containers, use [Multi-study export](/docs/guides/bulk-operations/export/).

Study and subject totals are not here. They are on the [Dashboard](/docs/guides/getting-started/dashboard/) and on the admin **System Statistics** page.

## Layout

1. **Filters** (collapsible), then chips.
2. Four summary cards, in order: total specimens, total containers, storage locations, container types in use.
3. **Timeline chart display.** Bin size (daily, weekly, monthly, quarterly, yearly), minimum date, and presets: Last 30 days, Last 6 months, This year, All time. These options apply only to Collection Timeline and Creation Timeline in the sections below.
4. Three sections: **Specimen Overview**, **Container Overview**, and **Storage Utilization**. Each has a summary line and pie or bar charts.

## Charts

**Storage Utilization.** **Top Storage Locations** (most containers) and **Containers by Root Location**. Collection-type counts (how many plates, boxes, bags) are on admin **System Statistics**, not here.

**Specimen Overview.** Distribution by specimen type, and **Specimens by Study**.

**Container Overview.** Counts by container type: micronix, cryovial, paper, static well.
