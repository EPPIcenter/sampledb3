---
title: Units
description: Symbols, names, and categories for quantities
---

Units appear on container quantity fields. Open **Reference Data → Units**. Columns are **Symbol**, **Name**, and **Category**.

Click **Add New** to open **Add Units**. Enter **Symbol** (for example `mL` or `µL`), **Name** (Milliliter), and **Category**: Volume, Mass, Count, Concentration, or Other.

Default units per container type are set in [Application Settings](/docs/guides/advanced/settings/) under **Container Type Units**, not here.

You can edit a unit after creation. A change appears everywhere that unit is used. You cannot delete a unit that is still referenced. Update those records first.

If a unit does not appear in a dropdown, confirm it exists on this tab. Names and symbols are case-sensitive: `mL` is not `ml`. Check that the unit is allowed for that container type in Application Settings.
