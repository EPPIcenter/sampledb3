---
title: Storage types
description: Categories assigned to locations
---

Storage types categorize locations: -80°C Freezer, -20°C Freezer, 4°C Refrigerator, Room Temperature, Liquid Nitrogen, and any others you add.

Open **Reference Data → Storage Types**. The table shows name and description.

Click **Add New** to open **Add Storage Types**. Enter a name, optionally a description, and save. Root locations require a storage type; child locations inherit from the parent. You assign the type on the Locations page, not here. See [Locations](/docs/guides/workflows/locations/).

You can edit name and description after creation. You cannot delete a storage type that is still assigned to locations. Change those locations first.

If a type does not appear when creating a root location, confirm it exists on this tab and that the name matches exactly.
