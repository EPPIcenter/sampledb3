**Reference Data** also has **Strains** and **Tags**. Reagents, cell lines, plasmids, and standards appear as specimen sources but are not tabs here.

## Strains

Parasite strains used in blood control compositions. The table has a name and optional description. Click **Add New** or **Edit**.

When you create a control definition, you pick strains and percentages that must total 100%. See [Blood controls](/docs/guides/features/blood-controls/).

## Tags

Labels on **containers** only, not specimens. A tag is a name; there is no description field. Click **Add New**.

Exports and statistics can include only containers that have all selected tags.

## Reagents, cell lines, plasmids, and standards

These are not Reference Data tabs and have no create screens in the app. On specimen registration, **Source Type** includes **Reagent**, **Cell Line**, **Plasmid**, and **Standard**. You can pick an existing record of that type. To add new records, contact an administrator.

## Delete

You cannot delete a strain or tag that is still referenced. Update or remove those references first.
