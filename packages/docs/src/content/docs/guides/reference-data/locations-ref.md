---
title: Where to manage locations
description: Locations are not a Reference Data tab
---

There is no Locations tab in Reference Data. Build the storage tree on **Browse Data → Locations**.

That page shows the hierarchy, collections at each node, and (with write access) add and edit controls. For the full workflow, see [Locations](/docs/guides/workflows/locations/).

The related reference-data type is **Storage Types**. You assign a type when you create a root location. Manage the type list on **Reference Data → Storage Types**. See [Storage types](/docs/guides/reference-data/storage-types/).
