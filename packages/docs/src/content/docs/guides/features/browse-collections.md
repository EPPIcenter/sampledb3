---
title: Browsing Collections
description: Search and discover plates, boxes, and bags in one place
---

The **Collections** page (Browse Data → Collections) lets you discover and open any collection—micronix plates, cryovial boxes, boxes, and bags—from a single table with search and filters. Use it when you want to find a specific plate or box by name, barcode, or location without navigating the location tree.

## Opening the Collections page

In the sidebar, go to **Browse Data** → **Collections**. You can also use the command palette (keyboard shortcut or search icon) and choose **Go to Collections**, or type "collections", "plates", "boxes", or "bags" to jump there.

## Search

The search box at the top filters the table as you type. It matches:

- **Name** – collection name (e.g. plate or box name)
- **Barcode** – barcode if the collection has one (e.g. micronix plates, cryovial boxes)
- **Location path** – the full location path (e.g. `/Freezer A/Shelf 1`)

Search is case-insensitive and instant; no need to press Enter. Clear the search box to see all collections again.

## Type tabs

Use the tabs below the page title to restrict the list by collection type:

- **All** – every collection (default)
- **Micronix Plates**
- **Cryovial Boxes**
- **Boxes**
- **Bags**

The active tab is reflected in the URL (e.g. `?tab=cryovial_box`), so you can bookmark or share a filtered view.

## Table columns and opening a collection

The table shows:

- **Name** – click the name to open the collection detail page
- **Type** – Micronix Plates, Cryovial Boxes, Boxes, or Bags
- **Barcode** – if present
- **Location** – full path of the collection’s location
- **Items** – number of items (tubes, wells, or sheets) in the collection

You can also click anywhere on a row to open that collection’s detail page. Sorting is available on the Name, Type, and Items columns.

## Pagination

If there are many collections, the table is paginated (e.g. 50 per page). Use the pagination controls below the table to move between pages. The summary text shows how many collections are currently visible and whether the list is filtered.
