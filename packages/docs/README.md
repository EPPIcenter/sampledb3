# SampleDB user guide

Starlight site for lab staff and biobank operators. Pages live in `src/content/docs/`. The app serves the built site at `/docs`.

## Commands

Run these from the repo root:

| Command | Action |
| --- | --- |
| `bun run dev:docs` | Dev server (see the terminal for the port; paths stay under `/docs/`) |
| `bun run build:docs` | Production build |
| `bash packages/docs/scripts/check-stale-claims.sh` | Fail if known-stale UI claims remain (`ci:verify` runs this) |

Sidebar groups are set in `astro.config.mjs`. Guide files under `src/content/docs/guides/` are autogenerated into those groups.

UI labels in the guides must match `packages/web`. Re-dump them with `bash packages/docs/scripts/dump-ui-labels.sh` after web copy changes.
